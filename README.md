# Hugging Face Agents Course — материалы и агент для финального задания

Репозиторий с материалами по прохождению курса [Hugging Face Agents Course](https://huggingface.co/learn/agents-course):
полный конспект, презентация, трекер прогресса и готовый код агента для финального задания (бенчмарк GAIA, Unit 4).

## Содержимое

- **`Курс_AI_Agents_конспект_полный.docx` / `.pdf`** — полный конспект курса на русском языке: Unit 0–4 и все три бонусных модуля,
  с диаграммами и примерами кода.
- **`AI_Agents_Course_презентация.pptx`** — краткая презентация курса (12 слайдов): архитектура агентов, фреймворки
  (smolagents / LlamaIndex / LangGraph), бенчмарк GAIA, сертификаты.
- **`AI_Agents_Course_трекер.xlsx`** — трекер прогресса по юнитам, глоссарий терминов, сравнение фреймворков,
  чек-лист для финального задания GAIA.
- **`diagrams/`** — исходные PNG-диаграммы, использованные в конспекте и презентации.
- **`gaia_agent_space/`** — готовый код агента (`smolagents.CodeAgent`) для финального задания Unit 4 и инструкция
  по публикации на Hugging Face Spaces (`ИНСТРУКЦИЯ_по_публикации.md`).

## Статус

- ✅ Конспект, презентация и трекер по всему курсу (включая бонусные модули) — готовы.
- ⏳ Unit 4 (финальное задание, бенчмарк GAIA) — код агента готов в `gaia_agent_space/`, публикация Space,

## Как опубликовать GAIA-агента

Подробные шаги — в [`gaia_agent_space/ИНСТРУКЦИЯ_по_публикации.md`](gaia_agent_space/ИНСТРУКЦИЯ_по_публикации.md).
Кратко: создать публичный Space (SDK Gradio) на huggingface.co, загрузить туда файлы из `gaia_agent_space/`,
добавить секрет `HF_TOKEN`, запустить оценку в приложении.
